# 通域书签导航
通域书签导航是一个简洁、轻量的 PHP + MySQL 书签导航 / 网址大全系统，支持无限级分类、用户个人收藏夹、便签、站点公告、广告位、后台管理、回收站、书签一键去重与浏览器扩展双向同步等功能。
## 功能特性

### 前台
- **网址大全**：由管理员在后台添加的系统书签，面向所有访客；支持三种首页显示模式（整栏、预览卡、导航栏目），后台可对每个系统分类单独设置
- **用户个人收藏夹**：每个用户有独立的公开页面，地址格式 `https://域名/u/用户名`
- **无限级分类**：支持无限层级分类嵌套
- **便签**：用户可创建纯文本便签
- **页面**：管理员可创建 HTML 页面（关于页、公告页、公司文化等）
- **站点公告**：管理员可在后台发布全站公告
- **广告位**：管理员可在后台配置页头 / 页脚广告代码
- **密码保护**：分类和页面可设置访问密码
- **搜索**：支持书签搜索（`search.php`）
- **回收站（软删除）**：删除的书签 / 分类 / 页面进入回收站，支持**批量恢复**与**批量彻底删除**，可按保留天数自动清理
- **书签一键去重**：按所选分类（可含子分类）范围，将 **URL 完全相同**的书签仅保留一个，其余移入回收站（后台「系统书签」与用户「我的收藏」均支持）
- **列表「访问」快捷按钮**：分类列表（后台 / 用户侧）操作列新增「访问」按钮，一键打开对应分类页
- **浏览器扩展双向同步**：提供 Chrome/Edge 与 Firefox 扩展，支持系统书签与浏览器书签的下载 / 上传 / 双向同步（含同名分类粘性处理与覆盖删除保护）

### 用户中心（`user/`）
- 书签管理（添加、编辑、删除、公开/私有；列表支持**双击行内直接修改标题 / URL / 排序**，不必逐个进编辑页；可按**域名 / 重复域名 / 重复标题**筛选快速定位重复项）
- 分类管理（无限级、密码保护；列表显示每个分类下的「书签 N · 页面 M」数量）
- 便签管理（纯文本）
- 个人资料设置（含远程头像 URL）、修改密码
- 书签导入 / 导出（CSV）

### 账号与安全
- **注册**：支持开放注册（后台可开关），含邮箱格式校验与频率限制
- **邮箱验证**：注册后发送验证邮件，点击链接激活邮箱（`verify.php`）
- **找回密码**：通过邮箱发送重置链接，30 分钟内有效（`forgot_password.php` + `reset_password.php`）
- 以上邮件功能需在后台「系统设置 → 邮件(SMTP)」中配置发信服务（如腾讯 QQ 邮箱的 SMTP + 授权码）

### 后台管理（`admin/`）
- 概览
- 用户管理（查看用户内容、禁用/启用、赋予/撤销管理员、删除用户）
- 系统分类管理（网址大全分类，列表显示每个分类下的「书签 N · 页面 M」数量；支持设置分类在首页的显示方式：整栏 / 预览卡 / 导航栏目 / 不显示）
- 用户管理中的密码重置：受权限严格限制（超级管理员与普通管理员均不能重置自己的密码，管理员之间也不能互改密码）
- 系统分类管理（网址大全分类，列表显示每个分类下的「书签 N · 页面 M」数量）
- 系统书签管理（网址大全书签，列表支持**双击行内直接修改标题 / URL / 排序**；可按**域名 / 重复域名 / 重复标题**筛选快速定位重复项）
- 页面管理（HTML 页面）
- 站点公告管理
- 广告管理（页头 / 页脚广告代码）
- 操作日志（完整记录所有用户操作，便于安全管控）
- 系统设置（网站名称、描述、注册开关、ICP 备案、SMTP 邮件、首页预览卡数量等）
- 全站书签导入 / 导出

### 权限体系
- **普通用户**：管理自己的书签、分类、便签
- **管理员**：拥有普通用户所有功能 + 后台管理权限
- **超级管理员（id=1）**：拥有所有权限，可赋予/撤销其他用户管理员权限，不可被编辑或删除

## 环境要求

- PHP >= 8.0（推荐 PHP 8.3，已在 8.3 下验证；代码使用 `match()` 等 8.0+ 语法）
- MySQL >= 5.7（或 MariaDB >= 10.2）
- 必需扩展：PDO、pdo_mysql、mbstring、json、session、openssl（邮件功能依赖）
- 宝塔面板（Linux）推荐环境

## 安装步骤

### 方式一：宝塔面板一键部署（推荐）

1. **上传文件**：将本程序所有文件上传到网站根目录
2. **创建数据库**：在宝塔面板中创建 MySQL 数据库，记录数据库名、用户名、密码
3. **运行安装程序**：浏览器访问 `https://你的域名/install/install.php`
4. **填写信息**：
   - 数据库主机：默认 `localhost`
   - 数据库端口：默认 `3306`
   - 数据库名：你创建的数据库名
   - 数据库用户名/密码：数据库的用户名和密码
   - 表前缀：默认 `bm_`（建议保持默认）
   - 管理员用户名/密码：设置超级管理员账号
5. **完成安装**：点击「开始安装」，等待安装完成
6. **安全加固**：安装完成后，**强烈建议删除整个 `install/` 目录**（含升级脚本），以缩小攻击面

### 方式二：手动安装

1. 上传文件到网站根目录
2. 创建数据库并导入 `install/schema.sql`（需手动替换表前缀 `{prefix}`）
3. 复制配置文件：参考安装生成的 `config.php` 格式手动创建
4. 在数据库中手动添加管理员账号（密码需使用 `password_hash()` 加密）
